# Twelv — Offline-First 12-Week Execution Planner

A mobile productivity and execution app built around the 12-Week Year methodology.

## Key Features

- 84-Day Execution Cycles
- Task Scheduling & Rollover
- Weekday Habit Tracking
- Weekly Inspiration Quotes
- 85% Execution Analytics
- Offline JSON Backup & Restore

## Tech Stack

- React Native & Expo
- TypeScript (Strict Mode)
- Local SQLite (expo-sqlite)
- Expo Application Services (EAS)

## Local Setup

```bash
npm install
npx expo start
